## 日志分级与保留

Sentry 是星野科技的集中日志平台，日志级别为 debug / info / warn / error / fatal 五级，采集默认忽略 debug。保留期按存储层划分：

- 热存：7 天，支持全文检索与聚合分析，用于日常排障；
- 冷存：180 天，存放于对象存储，按需恢复，单次恢复最长 4 小时；
- 审计类日志：由审计要求单独管理，保留期限见审计与取证规范，不适用本节热存/冷存规则。

## 查询权限

| 行为 | 所需流程 | 说明 |
|---|---|---|
| 常规只读查询 | AR-1 | 默认授予 90 天，到期自动回收 |
| 查询明文个人信息字段 | DE-2 明文导出审批 | 单次导出上限 500 万行 |
| 批量落盘导出 | DE-1 或 DE-2 | 视脱敏情况而定 |

平台默认对 user_id、手机号、身份证号做掩码，查询结果页面只展示脱敏后的值。需要明文检索或导出含个人信息的原始日志，必须走 DE-2 明文导出流程，并在申请单里写明字段清单与检索条件。

## 限制与超时

- 单次查询超时阈值 120 秒，超时后自动截断结果并提示缩小时间范围；
- 禁止把查询结果直接落盘到个人终端或转发到个人邮箱；
- 禁止绕开平台使用数据库直连或命令行工具查询生产日志，确需直连的按 AR-3 规则申请；
- 日志采集代理异常导致的日志缺口，需在 1 个工作日内由系统负责人确认并补采。

Sentry 的告警规则与 Nebula 的发布窗口联动：窗口期内错误类告警阈值临时收紧，避免发布噪声淹没真实故障。
